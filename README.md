# 🐍 Python Шпаргалка — macOS

Приложение-шпаргалка по языку Python для работы в macOS: все команды,
конструкции, коллекции, функции, ООП, asyncio, стандартная библиотека,
pytest и утилиты — в одном окне браузера.

## Запуск

```bash
cd python-cheatsheet

# вариант 1 — локальный сервер + авто-открытие браузера
python3 cheatsheet.py

# вариант 2 — просто открыть index.html (тоже работает офлайн)
python3 cheatsheet.py --static
```

Также можно дважды щёлкнуть по `index.html` в Finder.

## Возможности

- 🔎 Поиск по заголовкам, описаниям и коду (`⌘K`, `Esc` — очистить)
- 🗂 17 категорий: Быстрый старт · Терминал · Типы · Строки · Коллекции ·
  Условия · Функции · ООП · Исключения · Итераторы · Файлы · Типизация ·
  Async · Стандартная библиотека · Тесты · Сниппеты · macOS
- ⭐ Избранное: звёздочка на карточке, пункты хранятся в `localStorage`
- 🌙 Тёмная тема (кнопка в шапке, светлая/тёмная запоминается)
- 📋 Кнопка «Copy» копирует каждый сниппет в буфер обмена
- 📱 Адаптивная верстка + стили для печати (⌘P)

## Структура

```
python-cheatsheet/
├── index.html      — каркас приложения
├── style.css       — дизайн в стилистике macOS
├── data.js         — всё содержимое шпаргалки (категории и карточки)
├── app.js          — логика: поиск, фильтры, избранное, тема
└── cheatsheet.py   — лаунчер: http.server + открытие браузера
```

## Как добавить карточку

В `data.js` найди категорию и допиши элемент:

```js
{
  t: "Заголовок карточки",
  d: "Короткое описание.",
  code: r`cmd --flag          # комментарий
second line`
}
```

Категорию можно добавить объектом в массив `window.CATEGORIES` —
она сразу появится в меню.
