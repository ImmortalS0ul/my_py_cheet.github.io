# 🐍 Python Шпаргалка — универсальная

Универсальная статическая шпаргалка по Python. Работает прямо в браузере:
без сборки, сервера и установки Python. Открывается офлайн с локального диска
и публикуется как обычный сайт через GitHub Pages.

Репозиторий: <https://github.com/ImmortalS0ul/my_py_cheet.github.io>

## Открыть сайт

- Локально: дважды щёлкните по `index.html`.
- Через локальный сервер:

```bash
python3 -m http.server 8000
# затем http://localhost:8000/index.html
```

- Необязательный лаунчер (только для удобства): `python3 cheatsheet.py`.
  Он не нужен для работы сайта и для GitHub Pages.

## GitHub Pages

1. В репозитории откройте **Settings → Pages**.
2. **Build and deployment → Source:** `Deploy from a branch`.
3. Выберите ветку `main` и папку `/ (root)`, нажмите **Save**.
4. После публикации сайт будет доступен по адресу
   `https://immortals0ul.github.io/my_py_cheet.github.io/`.

Сборка не требуется: достаточно файлов `index.html`, `style.css`, `data.js`, `app.js`.

## Возможности

- 🔎 Поиск по заголовкам, описаниям, теории, терминам и коду (`Ctrl/⌘K`, `Esc` — очистить)
- 📘 У каждой карточки есть блоки «Простыми словами», «Теория» и «Термины»
- 🗂 19 разделов, 136 карточек: старт, терминал, типы, строки, коллекции, условия,
  функции, ООП, исключения, итераторы, файлы, типизация, стандартная библиотека,
  тесты, сниппеты, базы данных, SQLite, SQLAlchemy и MicroPython на EV3
- 🤖 Отдельный блок по EV3: только моторы и датчики Pybricks
  (<https://pybricks.com/ev3-micropython/>), без NXT и других платформ
- ⭐ Избранное — звёздочка на карточке; хранится в `localStorage` (`pycheat:favs`)
- 🌙 Светлая/тёмная тема с автоопределением и сохранением (`pycheat:theme`)
- 📋 Кнопка копирования сниппета (работает и по `file://`)
- 🖨 Печать / сохранение в PDF через кнопку в шапке
- ⬇️ Экспорт текущей подборки в Markdown
- 📱 Адаптивная вёрстка для телефона, планшета и десктопа; безопасные отступы для iPhone

Сайт не зависит от локального Python-лаунчера: `cheatsheet.py` — лишь необязательная мелочь.

## Как добавить карточку

В `data.js` допишите элемент в нужную категорию:

```js
{
  t: "Заголовок карточки",
  d: "Короткое описание.",
  simple: "Объяснение простыми словами, как для ученика, который видит тему впервые.",
  theory: "Несколько предложений: суть механизма, зачем он нужен и типичное применение.",
  terms: [
    { term: "Термин", def: "Краткое определение одним предложением." }
  ],
  code: r`print("Привет")`
}
```

Поля `simple`, `theory` и `terms` показываются на карточке и участвуют в поиске.
Новую категорию добавьте объектом в `window.CATEGORIES` — она появится в меню автоматически.
